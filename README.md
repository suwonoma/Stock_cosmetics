# 일본 화장품 산업 대시보드

일본 주요 화장품 기업의 뉴스, 주가, AI 연구를 추적하는 종합 웹 대시보드입니다.

## 주요 기능

### 1. 최신 뉴스 섹션
- 일본 화장품 기업의 실시간 산업 뉴스
- 회사 및 카테고리별 필터링
- 자동 캐싱 (1시간 TTL)
- 카테고리: 신제품, 재무실적, M&A, 연구개발, ESG
- **뉴스 카드 클릭 시 실제 회사 웹사이트로 이동**

### 2. 주가 차트
- Chart.js를 활용한 인터랙티브 주가 시각화
- 다양한 기간 지원 (1주, 1개월, 3개월, 6개월, 1년, 연초대비)
- 최대 4개 회사 동시 비교
- 실시간 가격 지표 및 52주 최고/최저가
- 자동 캐싱 (15분 TTL)

### 3. AI 연구 논문
- 화장품 분야 AI 응용 학술 논문
- 검색 및 필터링 기능
- 연도별 필터링
- arXiv 및 학술 데이터베이스 통합
- 성능 향상을 위한 24시간 캐시

### 4. 추가 기능
- 다크/라이트 테마 전환
- 완전 반응형 디자인 (모바일, 태블릿, 데스크톱)
- API 호출 감소를 위한 로컬 스토리지 캐싱
- 부드러운 애니메이션 및 전환 효과
- 화장품에서 영감받은 깔끔하고 모던한 UI
- **모든 UI 및 메시지 완전 한글화**

## 기술 스택

- **프론트엔드**: HTML5, CSS3, Vanilla JavaScript (ES6 모듈)
- **차트**: Chart.js 4.4.1
- **아이콘**: Font Awesome 6.5.1
- **호스팅**: GitHub Pages (정적 호스팅)
- **API**: NewsAPI, Alpha Vantage, arXiv

## 설치 방법

### 1. 저장소 클론

```bash
git clone https://github.com/suwonoma/Stock_cosmetics.git
cd Stock_cosmetics
```

### 2. API 키 설정 (선택사항)

실제 데이터로 프로덕션 사용을 위해 API 키 설정이 필요합니다:

#### NewsAPI
1. [NewsAPI.org](https://newsapi.org/)에서 가입
2. 무료 API 키 발급
3. `js/news.js` 파일을 수정하여 API 키 추가

#### 주가 데이터 - Alpha Vantage
1. [Alpha Vantage](https://www.alphavantage.co/)에서 가입
2. 무료 API 키 발급
3. `js/stocks.js` 파일을 수정하여 API 키 추가

#### arXiv API
API 키가 필요 없습니다! arXiv API는 무료이며 오픈되어 있습니다.

### 3. 로컬 개발

웹 브라우저에서 `index.html`을 열기만 하면 됩니다:

```bash
# Python 내장 서버 사용
python -m http.server 8000

# 또는 Node.js 사용
npx http-server

# 그런 다음 http://localhost:8000 방문
```

### 4. GitHub Pages 배포

1. 코드를 GitHub에 푸시
2. Settings → Pages → Source: main branch, root folder 선택
3. 사이트가 다음 주소에서 이용 가능: `https://suwonoma.github.io/Stock_cosmetics/`

## 주요 특징

### 완전 한글화
- 모든 UI 요소가 한글로 표시
- 날짜 포맷: "오늘", "어제", "N일 전"

- 디바운싱: 검색 입력 디바운싱으로 처리 최소화
- CDN: CDN에서 외부 라이브러리 로드
